Duka POS

2026
Node.js/Express & PostgreSQL backend · React/Vite/Tailwind frontend

A full-stack point-of-sale system for supermarkets, covering the whole retail loop: selling, receiving stock, returns, expenses, and M-Pesa payments. The backend is fully built and tested; the frontend UI is built against the real API and pending a first visual/click-through pass before I'd call it launch-ready.

  • JWT authentication with rotating, hashed refresh tokens and stolen-token reuse detection.
  • Atomic sale transactions with server-side price/tax computation and DB-enforced oversell rejection.
  • M-Pesa Daraja STK Push integration — stock reservation on initiation, amount-trust-hardened callback handling so a forged callback can't under-record a sale.
  • Role-based access control enforced at the database and API layer across products, purchasing, returns, and expenses.
  • 40 automated tests (Jest + Supertest) running against a real PostgreSQL database, covering auth, sales, purchasing, returns, expenses, and reporting.
